# 奨也の道 — 画像生成プロンプト集（ChatGPT 用）

アプリをかっこよくするための画像を ChatGPT（画像生成）に頼むときのプロンプト。
**使い方**：各プロンプトの英語部分をそのまま貼る。最初に「共通スタイル」を貼ってから、画像ごとのプロンプトを続けると統一感が出る。

できた画像は `~/奨也の道/画像/` に、下の **ファイル名** で保存してください（そのまま組み込みます）。

---

## 共通スタイル（毎回、先頭に貼る）

```
Style guide for all images in this set:
- Theme: cool, sporty, Japanese pro-baseball video game style (like a modern baseball RPG / player card game), exciting and dynamic
- Color palette: deep navy #0C1C35 (base), vivid blue #247BDE, lime green #A8E66C (accent), white #FFFFFF. Use lime green as glowing highlights
- Lighting: night game stadium lights, slight glow, high contrast, clean
- Rendering: polished 2D game illustration / semi-flat with soft shading, crisp edges, no photo realism
- Audience: a 10-year-old boy; energetic but tasteful
- No text, no letters, no numbers, no logos, no real team emblems, no real players
- High resolution
```

## 1. アプリアイコン　→ `icon.png`

正方形。ホーム画面に置いたとき映えるもの。

```
App icon, 1:1 square. A baseball diamond seen from above in lime green on a deep navy rounded-square background, a glowing white baseball at the center with blue stitching, subtle stadium light rays from the top. Bold, simple, readable at small size. Flat game-style icon, no text.
```

## 4. 主人公キャラクター（3ポーズ）　→ `hero-stand.png` / `hero-ready.png` / `hero-swing.png`

**背景透過 PNG**。帽子ネイビー、白ユニフォーム、青いライン、黄緑のアクセント（手袋・スパイク）。
※アプリ内のキャラは今は SVG で「アイテム装備で見た目が変わる」仕組み。生成画像に替えると装備は反映されないので、**オープニングと選手カードの大きな絵**に使うのが現実的です。

```
Original character design of a 10-year-old Japanese boy baseball player, full body, transparent background (PNG). Navy blue baseball cap, white uniform with vivid blue piping, lime green batting gloves and lime accents on navy cleats, short black hair, confident bright smile, big expressive eyes, cool anime-game style (like a baseball RPG character), clean outlines, soft cel shading. Pose: standing proudly holding a wooden bat over his shoulder. No text, no logos, no number on the uniform.
```

残り2ポーズは最後の「Pose:」だけ替える：
- `hero-ready.png` → `Pose: fielding ready stance, knees bent, glove low to the ground, eyes focused, viewed from the front.`
- `hero-swing.png` → `Pose: dynamic mid-swing with the bat, body rotating, dust and speed lines, exciting.`

同じキャラにするコツ：1枚目ができたら、その画像を添付して「同じキャラクターで、ポーズだけ変えて」と頼む。

---

## 頼むときのコツ

- 1枚ずつ頼む（まとめて頼むと画風がばらつく）
- 「共通スタイル」を**毎回**先頭に貼る
- 気に入った1枚ができたら、その画像を添付して「この画風で」と続けると揃う
- 文字は入れない（文字はアプリ側で出す。生成画像の文字は崩れやすい）
- 透過が必要なものは「transparent background PNG」と書いても背景が付くことがある。その場合は画像を渡してくれれば、こちらで背景を抜きます
- サイズは「できるだけ大きく」（2048px 以上）。縮小はこちらでやります

## もらった後にこちらでやること

1. `~/奨也の道/画像/` に入れてもらう（上のファイル名で）
2. 透過・縮小・WebP 変換して `public/img/` に配置
3. 各画面に組み込み（オープニング背景・ホームカード・アイテム・メダル・ロードマップ・演出）
4. `sw.js` の VERSION を上げて公開
