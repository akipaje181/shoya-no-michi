# 奨也の道 — 画像プロンプト 第3弾（第2弾の作り直し・1枚ずつ 1024px 以上）

第2弾は「一覧画像からの切り出し」だったため 100〜300px と小さく、バナーなどがぼやけました。
今回は **1回の依頼で1枚だけ**、**1024px 以上**で作ってもらいます。

保存先：`~/奨也の道/画像/第3弾/` に、下の **ファイル名** で（1枚ずつ、そのままのサイズで保存。縮小しない）。
できたら「第3弾を入れた」と言ってください。こちらで透過・縮小・組み込み・公開まで行います。

---

## ChatGPT への頼み方（必ず守る 5つ）

1. **1回の依頼で1枚**。「まとめて」「一覧で」とは言わない。「一覧にせず、この1枚だけを画像全体に大きく描いてください」と添える
2. **サイズを明示**：「1024×1024 以上」（横長は 1536×512 以上、縦長は 1024×1536 以上）
3. **透過にしたいものは「真っ黒（#000000）の背景」**。「透明背景」とは言わない
4. **文字・数字・ロゴは入れない**（文字はアプリ側で出す）
5. **主人公は 第1弾の `hero-stand.png` を添付**して「同じキャラクター。帽子のマークは S」と書く（第2弾は帽子が A になっていた）

最初に下の「共通スタイル」を貼り、続けて画像ごとのプロンプトを貼る。

### 共通スタイル（毎回、先頭に貼る）

```
Style guide:
- Cool, sporty Japanese pro-baseball video game style (modern baseball RPG / player card game), exciting and dynamic
- Palette: deep navy #0C1C35, vivid blue #247BDE, lime green #A8E66C, white. Lime green as glowing highlights
- Night-game stadium lighting, soft glow, high contrast, crisp edges, polished 2D game illustration
- For a 10-year-old boy; energetic but tasteful
- No text, no letters, no numbers, no logos, no real team emblems, no real players
- ONE image only, the subject fills the frame. Do not make a sheet, grid, or multiple variations
- Output at 1024x1024 pixels or larger
```
