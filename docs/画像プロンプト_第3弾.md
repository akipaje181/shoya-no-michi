# 奨也の道 — 画像プロンプト 第3弾（1枚ずつ・1024px 以上）

## 使い方（2通り。おすすめは ①）

**① 丸ごと渡して、あとは「次」と言うだけ**
1. ChatGPT の新しいチャットを開き、第1弾の `画像/奨也の道_画像/hero-stand.png` を添付する
2. **このファイルの中身を全部コピーして貼る**（下の「ChatGPT への指示書」が先頭にあるので、ChatGPT は自分で順番に作り始める）
3. 1枚できるたびに、「次」とだけ打つ（何か打てば次へ進む。やり直したいときは「A-1 をやり直し」のように番号で言う）
4. できた画像は **縮小せず**、ChatGPT が表示する **ファイル名** で `~/奨也の道/画像/第3弾/` に保存する

**② 1枚ずつ自分で貼る**
各画像の灰色の枠をまるごとコピーして貼る（1枠にその画像に必要なことが全部入っている）。

全部で 37 枚。終わったら Claude に「第3弾を入れた」と言ってください。

```

1. 1回の返答で、1枚だけ画像を生成する。複数枚を1枚にまとめた一覧やグリッドは絶対に作らない。
2. 順番は 優先順位の通り：G-1→G-5、C-1→C-6、A-1、B-1→B-8、D-1→D-7、E-1→E-6、F-1、H-1→H-3。
3. 私が「次」「OK」「続けて」など何か返事をしたら、こちらから指示しなくても、自動的に次の番号へ進んで生成する。何を作るか聞き返さない。
4. 生成した画像の上に、必ず「番号」と「保存するファイル名」（例：G-1 banner-games.png）を1行で書く。説明文は不要。
5. 各枠の英語プロンプトをそのまま使う。サイズ（1024x1024 など）と「背景は真っ黒 #000000」の指示は必ず守る。文字・数字・ロゴは入れない。
```
