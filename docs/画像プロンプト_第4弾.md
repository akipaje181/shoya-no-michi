# 奨也の道 — 画像プロンプト 第4弾（絵文字アイコンを画像に・1枚ずつ 1024px）

いまアプリの中で絵文字（🏠 🎯 📅 🗣️ など）で表示しているマークを、きれいな画像に置きかえるためのプロンプト集です。全部で **48 枚**。

## 使い方（2通り。おすすめは ①）

**① 丸ごと渡して、あとは「次」と言うだけ**
1. ChatGPT の新しいチャットを開き、第1弾の `画像/奨也の道_画像/hero-stand.png` を添付する（F の気分の顔と H-2 のお父さんで使う）
2. **このファイルの中身を全部コピーして貼る**（下の「ChatGPT への指示書」が先頭にあるので、ChatGPT は自分で順番に作り始める）
3. 1枚できるたびに、「次」とだけ打つ（何か打てば次へ進む。やり直したいときは「B-3 をやり直し」のように番号で言う）
4. できた画像は **縮小せず**、ChatGPT が表示する **ファイル名** で `~/奨也の道/画像/第4弾/` に保存する（フォルダは作ってあります）

**② 1枚ずつ自分で貼る**
各画像の灰色の枠をまるごとコピーして貼る（1枠にその画像に必要なことが全部入っている）。

終わったら Claude に「第4弾を入れた」と言ってください。ChatGPT が自分の日本語ファイル名で保存してきても大丈夫です（こちらで対応づけます）。

---

## ChatGPT への指示書（この下をそのまま読んでください）

```
あなたは「奨也の道」というアプリの画像を作る担当です。この文書には 48 枚分の画像プロンプト（A-1 〜 H-2）が番号順に書いてあります。次のルールで作ってください。

1. 1回の返答で、1枚だけ画像を生成する。複数枚を1枚にまとめた一覧やグリッドは絶対に作らない。
2. 順番は 優先順位の通り：A-1→A-4、B-1→B-10、C-1→C-3、D-1→D-4、E-1→E-10、F-1→F-10、G-1→G-5、H-1→H-2。
3. 私が「次」「OK」「続けて」など何か返事をしたら、こちらから指示しなくても、自動的に次の番号へ進んで生成する。何を作るか聞き返さない。
4. 生成した画像の上に、必ず「番号」と「保存するファイル名」（例：A-1 tab-home.png）を1行で書く。説明文は不要。
5. 各枠の英語プロンプトをそのまま使う。サイズ 1024x1024 と「背景は真っ黒 #000000」は必ず守る（透明背景にしない。市松模様を描かない）。文字・数字・ロゴは入れない（クイズの「?」マークだけは可）。
6. これは小さく表示する「アイコン」なので、1つの物を大きく、シンプルに、くっきり描く。細かい背景や余計な小物は描かない。
7. F-7〜F-10（気分の顔）と H-2（お父さん）は、最初に添付した hero-stand.png を参照にする。奨也は同じ顔・髪・白いユニフォーム、帽子のマークは「S」。
8. 「B-3 をやり直し」「もっとシンプルに」のような指示が来たら、その番号だけ作り直し、そのあとは続きの番号に戻る。
9. 48 枚すべて終わったら「全部終わりました」と言う。
```
