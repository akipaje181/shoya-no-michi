# 奨也の道 — 画像プロンプト 第5弾（第4弾で届かなかったアイコン 24 枚の作り直し）

第4弾では ChatGPT がプロンプトと違うもの（文字入りのポスター・場面絵など）を多く作ったため、使えたのは一部でした。
この第5弾は **届かなかった 24 枚だけ**を、第4弾でうまくいった実物を見本にして作り直してもらうものです。

## 使い方（かならず この順）
1. ChatGPT の新しいチャットを開き、**最初に次の3枚を添付**する
   - `~/奨也の道/画像プロンプト用_参考画像/ref-icon-home.png`（第4弾でうまくいった家のアイコン）
   - `~/奨也の道/画像プロンプト用_参考画像/ref-icon-quiz.png`（同じくクイズのアイコン）
   - `~/奨也の道/画像/奨也の道_画像/hero-stand.png`（奨也の基準画像。E と G-2 で使う）
2. **このファイルの中身を全部コピーして貼る**
3. 1枚できるたびに「次」とだけ打つ（やり直しは「B-3 をやり直し」）
4. **できた画像は ZIP にまとめず、表示されたファイル名のまま 1枚ずつ** `~/奨也の道/画像/第5弾/` に保存する（ZIP にすると名前が化けて、どれがどれか分からなくなります）

終わったら Claude に「第5弾を入れた」と言ってください。

## ChatGPT への指示書（この下をそのまま読んでください）

```
あなたは「奨也の道」というアプリの小さなアイコン画像を作る担当です。この文書には 24 枚分のプロンプト（A-1 〜 G-2）が書いてあります。

1. 1回の返答で 1枚だけ生成する。一覧・グリッド・バリエーションは禁止。
2. 順番：A-1→A-2、B-1→B-6、C-1→C-2、D-1→D-3、E-1→E-4、F-1→F-5、G-1→G-2。
3. 私が「次」など何か返事をしたら、聞き返さずに次の番号へ進む。
4. 画像の上に「番号 ファイル名」（例：A-1 event-game.png）を1行だけ書く。説明は不要。
5. これは「アイコン」です。最初に添付した ref-icon-home.png / ref-icon-quiz.png と同じ絵柄・同じ質感で、1つの物だけを大きく描く。場面・ポスター・背景の風景・人物（指示があるものを除く）は描かない。
6. 文字は一切入れない（日本語も英語も数字も）。リボンや帯に文字を書かない。
7. サイズは必ず 1024x1024 の正方形。背景は真っ黒 #000000（透明にしない・市松模様を描かない）。
8. E-1〜E-4（気分の顔）と G-2（お父さん）は hero-stand.png を参照する。奨也は同じ顔・髪・白いユニフォーム、帽子のマークは「S」。
9. ファイル名はこちらが指定した名前をそのまま使い、ZIP にまとめない。
10. 24 枚すべて終わったら「全部終わりました」と言う。
```
