# Claude Code 開発指示書（2026-10-09 受領）

プロジェクト名：奨也の道（SHOYA'S ROAD）

（親から受け取った開発指示書の控え。設計は `docs/設計.md`、進捗は `docs/進捗.md`）

- キャッチコピー：走れ。守れ。打て。夢をつかめ。
- 対象：小学4年生の少年野球選手と保護者
- 配色：ネイビー #0C1C35／ブルー #247BDE／ライムグリーン #A8E66C／ホワイト #FFFFFF
- 必須画面：オープニング／ホーム／マイ選手／毎日の練習ミッション／成長グラフ／試合記録／動画アルバム／野球クイズ／トロフィー・アイテム／夢へのロードマップ／パパの応援
- XP 初期案：素振り30／守備40／走塁30／クイズ全問正解20／週間目標100（設定で変更可）
- 技術：Next.js・TypeScript・Tailwind・Supabase（未設定ならローカル保存の試作）・Recharts・PWA
- 重要事項：動くものを作る／見た目だけの機能を作らない／未実装は「準備中」／ペナルティなし／データが消えない／未設定の外部サービスに接続したふりをしない
